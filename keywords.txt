Programming language name : cclearly / Or cmotive
Filename extension : ccly
Compiled programming language


Operators: standard c++ programming language operators including New and Delete
All keywords start with caps.

Object oriented programming language.
With userspace thread support,
	 network programming support, 
	 file support, 
	 STL support,
	 io support,
	 logging support,
	 exception support,
	 filesystem support,
	 cross platform.

Support for processors 
	ARM, 
	Intel x86, 
	Intel 64 bit, 
	Mips, 
	Sparc, 
	PowerPC 
	and other processors
